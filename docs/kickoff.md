# Kickoff checklist

Friday 2 October 2026, 12:00, Nangang District, Taipei.

## Questions for the organisers

- Is code written before the event allowed, or must everything be built on site?
- Which challenges are still open, and is there a limit on teams per challenge?
- May one team submit to two challenges (7 and 8)?
- Which datasets are provided? Specifically the suggested navigation dataset for Challenge 2 and any audio for Challenge 7.
- Are the public datasets we downloaded acceptable? ESC-50 is licensed non-commercial and the drone audio set states no licence.
- What are the judging weights, the demo length and the submission format?
- Is hardware available to borrow (microphones, development boards, a drone to record)?
- Must the repository be public at submission?

## When forming the team

- Ask each person what they have built before, then match against "How to choose" in [pitches.md](pitches.md).
- Agree on one challenge and one fallback before leaving the kickoff.
- Agree on who owns which part. Each person should own something they can explain alone.
- Add everyone as a collaborator on the repository.

## First hour after choosing

- Each teammate runs the setup in the [README](../README.md).
- Write the demo script first, then cut the plan to what the demo needs.
- Fix shared conventions in writing: units, coordinate frames, file formats, branch names.
- Set a demo freeze for Sunday 12:00.
