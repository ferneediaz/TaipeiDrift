# Manifeste des données (piste C)

Mis à jour le 2026-10-03 par la piste C. Étiquettes : MEASURED (exécuté par nous sur des données réelles), SIMULATED (générateur déclaré), PUBLISHED (affirmation d'une source, avec lien), INFERENCE.
« Baro » : **brut** = pression mesurée (ou altitude calculée uniquement à partir de la pression) ; **fusionné** = altitude d'un estimateur ; **aucun** ; **inconnu**.
