# Data manifest (Track C)

Updated on 2026-10-03 by Track C. Labels: MEASURED (run by us on real data), SIMULATED (declared generator), PUBLISHED (claim from a source, with link), INFERENCE.
“Baro”: **raw** = measured pressure (or altitude calculated only from pressure); **fused** = altitude from an estimator; **none**; **unknown**.
